<Update label="0.4.0" description="2026-10-16">
  **FDI, interbank rates, trade by region, Japan GDP and debt breakdowns, BOJ ETF holdings.**

  Every dataset behind an "API" button in the HayInsights app now has its own
  reference page.

  **Added**

  - **Macro · FDI** — `GET /macro/fdi/flows`, `GET /macro/fdi/by-region` and
    `GET /macro/fdi/by-industry` (Japan, JETRO); `GET /macro/fdi/vn/flows` and
    `GET /macro/fdi/vn/breakdown` (Vietnam); `GET /macro/indicators/fdi`.
  - **Macro · Interbank rates** — `GET /macro/interbank-rates` (US/JP history),
    `GET /macro/interbank-rates/jp/tibor`, `GET /macro/interbank-rates/jp/overnight`,
    `GET /macro/interbank-rates/vn` (weight 3) and `GET /macro/indicators/interbank-rates`.
  - **Macro · Trade** — `GET /macro/trade/turnover` and `GET /macro/trade/by-region`.
  - **Macro · Japan** — `GET /macro/japan/gdp-breakdown` and
    `GET /macro/japan/central-gov-debt`.
  - **ETF** — `GET /etf/boj-holdings` and `GET /etf/boj-holdings/latest` (gated by
    `etf_data`, weight 2).

  New Macro routes are gated by `macro_data`.
</Update>

<Update label="0.3.0" description="2026-10-15">
  **Equities domain.**

  **Added**

  - **Equities** — Japanese stock detail for Tokyo Stock Exchange listings, under
    `/market/{market}/equities/{code}` (`market` is `jp` for now; `code` accepts
    `7203` or `72030`):
    - `GET /market/{market}/equities/{code}` — end-of-day snapshot: quote, overview,
      trading activity, period changes and TTM ratios.
    - `GET …/events` — dividends and earnings releases within ±30 days.
    - `GET …/prices` — daily closes, raw and split-adjusted.
    - `GET …/financial-statements` — income statement or balance sheet as a tree.
    - `GET …/related-stocks` — TSE 33-sector peers by market cap.

  Equities is gated by the existing `macro_data` feature code, like News, Calendar
  and Market.
</Update>

<Update label="0.2.0" description="2026-09-16">
  **News, Calendar and Market domains; Real Estate restructured.**

  Brings the specification in line with the deployed API — 57 endpoints across nine
  domains.

  **Added**

  - **News** — `GET /news/feed` (headlines with per-article sentiment) and
    `GET /news/sentiment` (aggregate reading over a rolling window).
  - **Calendar** — `GET /calendar/events`: rate decisions, CPI and GDP releases,
    market holidays and asset-level events.
  - **Market** — `GET /market/indices/snapshot` and `GET /market/global-indices`.
  - **Macro** — 13 `GET /macro/indicators/*` tables covering GDP, CPI, PPI, PCE,
    trade, population, unemployment, exchange rates, deposit rates and bond yields.
  - **Real Estate** — ward-level `GET /real-estate/{country}/provinces/{provinceId}/wards`
    and `/geojson`, province-level `GET /real-estate/{country}/provinces/prices`, and
    transaction-level `GET /real-estate/{country}/wards/{wardId}/transactions`
    (Japan only).

  News, Calendar and Market are gated by the existing `macro_data` feature code, so
  any plan that already includes Macro reaches them without a change of subscription.

  **Removed — breaking**

  Five Real Estate endpoints have been withdrawn. They were never exercised by a
  first-party client, and so carried no coverage guarantee:

  | Withdrawn | Replacement |
  | --- | --- |
  | `GET /real-estate/{country}` | — |
  | `GET /real-estate/{country}/stats` | — |
  | `GET /real-estate/{country}/geojson` | `GET /real-estate/{country}/provinces/{provinceId}/geojson` |
  | `GET /real-estate/{country}/wards` | `GET /real-estate/{country}/provinces/{provinceId}/wards` |
  | `GET /real-estate/{country}/wards/{wardId}` | `GET /real-estate/{country}/wards/{wardId}/transactions` |

  Ward access is now scoped to a province rather than a whole country. If you call
  any of the withdrawn routes, fetch the province list first and iterate.

  **Changed**

  - `GET /real-estate/{country}/provinces` accepts `country=all`, and every province
    now carries a `country` field so a combined response can be grouped client-side.
  - Province `bbox` is populated (it previously documented `null`), with offshore
    units excluded.
</Update>

<Update label="0.1.0" description="2026-06-19">
  **Initial preview release.**

  - 40 read endpoints across six domains: Commodities, Crypto, ETF, FX, Macro and
    Real Estate.
  - Single-tier authentication via the `X-API-Key` header.
  - Weighted, per-minute rate limiting with `X-RateLimit-*` headers.
  - Plan-based feature gating (`<domain>_data` feature codes).
  - Standard response envelope `{ success, statusCode, data, meta }`.
</Update>
